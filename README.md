# BWP HR Dashboard

แดชบอร์ดกำลังคนสำหรับผู้บริหารและฝ่ายบุคคล — บริษัท เบสท์เวิลด์ อินเตอร์พลาส จำกัด

**เว็บ:** https://hrbwp02-beep.github.io/bwp-hr-dashboard/

## มุมมองที่แสดง
1. สรุปจำนวนพนักงาน (Headcount Summary)
2. อัตราการลาออก (Turnover Rate)
3. การสรรหาและคัดเลือก (Recruitment Funnel) — ดึงตัวเลขรวมจากระบบสรรหา
4. การเข้างานและการลา — *รอระบบลา/บันทึกเวลา*
5. โครงสร้างพนักงาน (Demographics)

ตัวเลขทั้งหมดคำนวณสดจากข้อมูลจริงใน Supabase `BWPHRConnect` ไม่มีการประมาณค่า
